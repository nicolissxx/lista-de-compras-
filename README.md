# Lista de Compras

Integrantes: 
* Nicoli

Um sistema web desenvolvido em PHP para organizar listas de compras.

## Tecnologias 
* **PHP** (Backend)
* **HTML & CSS** (Interface)
* **Banco de Dados** (MySQL)

## Estrutura do Projeto
* `cadastro.php` - Formulário e lógica para cadastros.
* `conexao.php` - Arquivo de conexão com o banco de dados.
* `Contato.php` - Página de contato.
* `criarLista.php` - Funcionalidade para criar e visualizar listas.
* `header.php` - Cabeçalho padrão reutilizado nas páginas.

## Como Rodar o Projeto Localmente
1. Tenha um servidor local instalado (**WampServer**).
